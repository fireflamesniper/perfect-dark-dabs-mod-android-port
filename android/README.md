# Android

An APK of the game, played with a controller. It is the same code as the
desktop builds: SDL2's activity creates a GLES 3 surface, reads controllers and
runs `SDL_main` (`port/src/main.c`) from `libmain.so`.

## Building

Needs the Android SDK with NDK 27.0.12077973 and CMake 3.22.1 (SDK Manager),
JDK 17, and Python 3 on the host (the asset headers are generated by
`tools/assetmgr`). Point `local.properties` at the SDK (`sdk.dir=...`), or open
this folder in Android Studio, which writes it.

```sh
cd android
./gradlew assembleRelease          # app/build/outputs/apk/release/app-release.apk
adb install -r app/build/outputs/apk/release/app-release.apk
```

The first configure downloads SDL2's source (the version is in
`app/build.gradle`) into `deps/`. The release APK is signed with the debug
key so it installs as it is. Only `arm64-v8a` is built; `-PpdAbis=arm64-v8a,x86_64`
adds an emulator ABI.

## The ROM

The game reads everything from the app's external files folder:

```
/sdcard/Android/data/com.dabdavis.perfectdarkdabsmod/files/
    data/pd.ntsc-final.z64     <- the ROM goes here
    pd.ini, saves, added-content/, mods/ ...
```

Copy it there with a file manager, over USB, or with
`adb push pd.ntsc-final.z64 /sdcard/Android/data/com.dabdavis.perfectdarkdabsmod/files/data/`.
The folder exists once the app has been started once. No storage permission is
needed.

## Controls

Any controller Android or SDL's HIDAPI drivers know (Xbox, PlayStation,
Switch Pro, 8BitDo, SHIELD...) works the way it does on PC, binds included.
Back (the system bar's, or a pad's Back/Select when Android sends it as Back)
is Escape.

On-screen controls (`TouchControlsView.java`) are player 1's pad: the left of
the screen is the movement stick, a drag elsewhere looks, and the buttons are
the pad's (FIRE = RT, AIM = LT, USE = A, BACK = B, RELOAD = X, WEAPON = Y, ALT
= RB, RADIAL = LB, CROUCH = L3, PAUSE = Start), so the controller binds apply
and a real pad keeps working beside them. The TOUCH button top left turns them
off and on (remembered). While on, they hide when a gamepad connects and come
back at a touch.

The APK's libraries are stripped; `./gradlew assembleRelease -PpdKeepSymbols`
keeps the DWARF in them.

## What is missing

- **Online lobbies, Ghost Trials accounts, Check for Updates**: these speak
  HTTPS through libcurl, which the Android build does not have yet. LAN and
  Direct Connect matches (ENet, no HTTP) are compiled in.
- **Vulkan**: the renderer needs shaderc, not built for Android; OpenGL ES 3 is used.
- **Recording**: needs an ffmpeg executable.
- GPU vertices (`Video.GpuVertices`) are desktop GL only, so vertices are
  transformed on the CPU.
